## Налаштування середовища

Потрібен Python 3.10+.

```bash
pip install -r requirements.txt
```

## Запуск тестів

```bash
python -m pytest -v
```

## Запуск програми

```bash
python game_of_life.py input.txt output.txt
```

Формат `input.txt`: перший рядок — кількість поколінь, другий — ширина і висота поля,
далі рядки поля (`.` — мертва клітина, `x` — жива).
